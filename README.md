# La Esquina — Kiosco POS

Aplicación web de punto de venta, inventario y compras a proveedores construida con HTML, CSS y JavaScript puro.

## Ejecutar

Abre `index.html` directamente en el navegador o inicia un servidor local:

```bash
python3 -m http.server 8000
```

Los productos, ventas y compras se almacenan en `localStorage` del navegador.
