# Tu Esquina — Gestión de kiosco

Aplicación web responsive de punto de venta, inventario, compras, vencimientos e historial, construida con HTML, CSS y JavaScript puro.

## Ejecutar

Abre `index.html` directamente en el navegador o inicia un servidor local:

```bash
python3 -m http.server 8000
```

Los productos, ventas y compras se almacenan en `localStorage` del navegador. Los registros existentes se migran automáticamente al esquema actual sin eliminar información.
